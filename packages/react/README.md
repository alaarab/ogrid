# @alaarab/ogrid-react

React hooks and headless components for OGrid data grids.

## Install

```bash
npm install @alaarab/ogrid-react
```

You typically don't need to install this directly  -  the UI packages (`@alaarab/ogrid-react-radix`, `@alaarab/ogrid-react-fluent`, `@alaarab/ogrid-react-material`) re-export everything from this package.

```tsx
import { useOGrid, type IColumnDef } from '@alaarab/ogrid-react';
```

See the [OGrid docs](https://alaarab.github.io/ogrid/) for full documentation.
