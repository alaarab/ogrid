# @alaarab/ogrid-core

Pure TypeScript types, algorithms, and utilities shared by the OGrid React UI packages.

## Install

```bash
npm install @alaarab/ogrid-core
```

You typically don't need to install this directly — the React UI packages (`@alaarab/ogrid-react-radix`, `@alaarab/ogrid-react-fluent`) re-export everything from core.

```typescript
import type { IColumnDef, IDataSource } from '@alaarab/ogrid-core';
```

See the [OGrid docs](https://alaarab.github.io/ogrid/) for full documentation.
