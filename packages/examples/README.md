# OGrid Examples

Example applications for all OGrid UI packages across React, Angular, Vue, and vanilla JS.

## Running an example

```bash
# From the monorepo root  -  build packages first
npm run build

# Then start any example dev server
npm run dev:react-radix
npm run dev:react-fluent
npm run dev:react-material
npm run dev:angular-radix
npm run dev:angular-material
npm run dev:angular-primeng
npm run dev:vue-radix
npm run dev:vue-vuetify
npm run dev:vue-primevue
npm run dev:js
```

See the [OGrid docs](https://alaarab.github.io/ogrid/) for full documentation.
