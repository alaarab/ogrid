# Framework Showcase

OGrid renders with your design system's native components. Same API, same features — different look and feel. Every grid below is **fully interactive**: sort, filter, edit, select cells, copy/paste, and undo/redo.

## React

### Radix UI (Default)

The lightest option. Radix primitives are bundled — no peer dependencies beyond React. This is the same grid you see throughout the docs.

```bash
npm install @alaarab/ogrid-react-radix
```

### Fluent UI

Microsoft's design system. Buttons, dropdowns, and popovers all use Fluent UI v9 components. Best for **Microsoft 365 and SharePoint** projects.

```bash
npm install @alaarab/ogrid-react-fluent @fluentui/react-components
```

<ShowcaseFluentDemo />

### Material UI

Google's Material Design via MUI v7. Inputs, menus, and pagination use MUI components. Best for apps already on **Material Design**.

```bash
npm install @alaarab/ogrid-react-material @mui/material @emotion/react @emotion/styled
```

## Angular

### Angular Material

Angular Material v21 with signals-based reactivity. Zone-less by default, standalone components, no NgModule boilerplate.

```bash
npm install @alaarab/ogrid-angular-material @angular/material @angular/cdk
```

<div style={{ display: 'flex', gap: '8px', margin: '8px 0 16px' }}>
  <OpenInStackBlitz project={showcase.Angular} label="Open in StackBlitz" />
</div>

```typescript
import { Component } from '@angular/core';
import { OGridComponent } from '@alaarab/ogrid-angular-material';

@Component({
  standalone: true,
  imports: [OGridComponent],
  template: `<ogrid [gridProps]="gridProps" />`
})
export class GridComponent {
  gridProps = { columns, data, getRowId: (row) => row.id, defaultPageSize: 10 };
}
```

## Vue

### Vuetify

Vuetify 3 components with Vue Composition API composables. Full reactivity via `ref()` and `computed()`.

```bash
npm install @alaarab/ogrid-vue-vuetify vuetify
```

<div style={{ display: 'flex', gap: '8px', margin: '8px 0 16px' }}>
  <OpenInStackBlitz project={showcase.Vue} label="Open in StackBlitz" />
</div>

```vue
<script setup lang="ts">
import { OGrid } from '@alaarab/ogrid-vue-vuetify';

<template>
  <v-app>
```

## Comparison

| | React (Radix) | React (Fluent) | React (Material) | Angular (Material) | Angular (PrimeNG) | Vue (Vuetify) | Vue (PrimeVue) | Vanilla JS |
|---|---|---|---|---|---|---|---|---|
| **Package** | `ogrid-react-radix` | `ogrid-react-fluent` | `ogrid-react-material` | `ogrid-angular-material` | `ogrid-angular-primeng` | `ogrid-vue-vuetify` | `ogrid-vue-primevue` | `ogrid-js` |
| **Design system** | Radix Primitives | Fluent v9 | MUI v7 | Angular Material v21 | PrimeNG v21 | Vuetify 3 | PrimeVue 4 | CSS custom props |
| **Peer deps** | None (bundled) | `@fluentui/*` | `@mui/*`, Emotion | `@angular/material` | `primeng` | `vuetify` | `primevue` | None |
| **Framework** | React 17–19 | React 17–19 | React 17–19 | Angular 21 | Angular 21 | Vue 3.3+ | Vue 3.3+ | Any / None |
| **Reactivity** | Hooks | Hooks | Hooks | Signals | Signals | Composition API | Composition API | EventEmitter |
| **Dark mode** | CSS vars | Fluent tokens | MUI palette | Angular theming | PrimeNG themes | Vuetify theme | PrimeVue theme | `--ogrid-*` vars |
| **Bundle impact** | Smallest | Medium | Largest | Medium | Medium | Medium | Medium | Smallest |

All packages share the same **headless core** (`@alaarab/ogrid-core`) and pass the same **1012 tests**. Switching frameworks later is a matter of changing imports and wrapping in the appropriate provider.

## Choosing a Package

- **Start new with React?** Use **Radix** — lightest weight, zero peer deps, full feature parity.
- **Microsoft ecosystem?** Use **Fluent** — native look in Teams, SharePoint, Outlook.
- **Already using MUI?** Use **Material** — matches your existing theme and components.
- **Angular project?** Use **Angular Material** or **PrimeNG** — signals-based, zone-less, standalone components.
- **Vue project?** Use **Vuetify** or **PrimeVue** — Composition API composables, full reactivity.
- **No framework?** Use **Vanilla JS** — works anywhere, class-based API, CSS-only theming.
