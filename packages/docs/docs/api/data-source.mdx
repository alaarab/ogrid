# Data Source

The `IDataSource<T>` interface enables server-side data operations. When you pass a `dataSource` prop to `OGrid` instead of `data`, the grid delegates sorting, filtering, and pagination to your server.

## IDataSource&lt;T&gt;

```typescript
interface IDataSource<T> {
  fetchPage(params: IFetchParams): Promise<IPageResult<T>>;
  fetchFilterOptions?(field: string): Promise<string[]>;
  searchPeople?(query: string): Promise<UserLike[]>;
  getUserByEmail?(email: string): Promise<UserLike | undefined>;
}
```

| Method | Required | Description |
|--------|----------|-------------|
| `fetchPage` | Yes | Fetches a page of data from the server. Called whenever the page, page size, sort, or filters change. |
| `fetchFilterOptions` | No | Fetches the available options for a `multiSelect` column filter. Called when a filter with `optionsSource: 'api'` is opened. Receives the field name and returns a list of option strings. |
| `searchPeople` | No | Searches for people by a query string. Called by `people` type column filters as the user types. Returns an array of `UserLike` objects. |
| `getUserByEmail` | No | Resolves a single user by email address. Used to display people filter chips when restoring saved filters. |

## IFetchParams

Parameters passed to `fetchPage` describing what data the grid needs.

```typescript
interface IFetchParams {
  page: number;
  pageSize: number;
  sort?: { field: string; direction: 'asc' | 'desc' };
  filters: IFilters;
}
```

| Name | Type | Description |
|------|------|-------------|
| `page` | `number` | The requested page number (1-based). |
| `pageSize` | `number` | The number of items per page. |
| `sort` | `{ field: string; direction: 'asc' \| 'desc' }` | The current sort configuration, or `undefined` if no sort is active. `field` corresponds to a column's `columnId`. |
| `filters` | `IFilters` | The current filter state. A record mapping field names to filter values. See [Types](./types) for `IFilters` and `FilterValue`. |

## IPageResult&lt;T&gt;

The response shape returned by `fetchPage`.

```typescript
interface IPageResult<T> {
  items: T[];
  totalCount: number;
}
```

| Name | Type | Description |
|------|------|-------------|
| `items` | `T[]` | Array of row data for the requested page. |
| `totalCount` | `number` | Total number of items across all pages (after filtering). Used to calculate pagination controls. |

## Complete Implementation Example

```typescript
import { IDataSource, IFetchParams, IPageResult, UserLike } from '@alaarab/ogrid-core';

interface Project {
  id: number;
  name: string;
  status: string;
  owner: UserLike;
  budget: number;
}

const projectDataSource: IDataSource<Project> = {
  async fetchPage(params: IFetchParams): Promise<IPageResult<Project>> {
    const queryParams = new URLSearchParams({
      page: String(params.page),
      pageSize: String(params.pageSize),
    });

    if (params.sort) {
      queryParams.set('sortField', params.sort.field);
      queryParams.set('sortDirection', params.sort.direction);
    }

    // Serialize filters
    for (const [field, value] of Object.entries(params.filters)) {
      if (value === undefined) continue;

      if (Array.isArray(value)) {
        // multiSelect filter: send as comma-separated string
        queryParams.set(`filter_${field}`, value.join(','));
      } else if (typeof value === 'object' && 'email' in value) {
        // people filter: send the email
        queryParams.set(`filter_${field}`, value.email);
      } else {
        // text filter
        queryParams.set(`filter_${field}`, String(value));
      }
    }

    const response = await fetch(`/api/projects?${queryParams}`);
    if (!response.ok) {
      throw new Error(`Failed to fetch projects: ${response.statusText}`);
    }

    const data = await response.json();
    return {
      items: data.items,
      totalCount: data.totalCount,
    };
  },

  async fetchFilterOptions(field: string): Promise<string[]> {
    const response = await fetch(`/api/projects/filter-options/${field}`);
    if (!response.ok) {
      throw new Error(`Failed to fetch filter options for ${field}`);
    }
    return response.json();
  },

  async searchPeople(query: string): Promise<UserLike[]> {
    const response = await fetch(
      `/api/people/search?q=${encodeURIComponent(query)}`
    );
    if (!response.ok) {
      throw new Error('Failed to search people');
    }
    return response.json();
  },

  async getUserByEmail(email: string): Promise<UserLike | undefined> {
    const response = await fetch(
      `/api/people/by-email/${encodeURIComponent(email)}`
    );
    if (response.status === 404) return undefined;
    if (!response.ok) {
      throw new Error('Failed to get user');
    }
    return response.json();
  },
};
```

## Usage with OGrid

```typescript
import { OGrid } from '@alaarab/ogrid';

function ProjectsGrid() {
  return (
    <OGrid<Project>
      columns={columns}
      dataSource={projectDataSource}
      getRowId={(project) => project.id}
      defaultPageSize={25}
      onError={(error) => console.error('Grid error:', error)}
      aria-label="Projects"
    />
  );
}
```

## Client-Side vs Server-Side

| Feature | Client-side (`data`) | Server-side (`dataSource`) |
|---------|---------------------|---------------------------|
| **Data loading** | You provide the full array | Grid calls `fetchPage()` |
| **Sorting** | Handled in-memory by the grid | Your server sorts the data |
| **Filtering** | Handled in-memory by the grid | Your server filters the data |
| **Pagination** | Handled in-memory by the grid | Your server paginates the data |
| **Filter options** | Derived from the data array | Fetched via `fetchFilterOptions()` |
| **People search** | Not available | Via `searchPeople()` |
| **Best for** | Small datasets (< 10,000 rows) | Large datasets, existing APIs |

## Error Handling

When `fetchPage` throws an error, the grid catches it and calls the `onError` callback if provided. The grid also sets `isLoading` to `false` and preserves the last successfully loaded data.

```typescript
<OGrid<Project>
  columns={columns}
  dataSource={projectDataSource}
  getRowId={(p) => p.id}
  onError={(error) => {
    // Log, show toast, etc.
    console.error('Data fetch failed:', error);
  }}
/>
```

## Filter Value Shapes

The `filters` field in `IFetchParams` uses `IFilters`, which maps field names to values. The value shape depends on the filter type:

| Filter Type | Value Shape | Example |
|------------|-------------|---------|
| `text` | `string` | `{ name: "Alice" }` |
| `multiSelect` | `string[]` | `{ status: ["Active", "Pending"] }` |
| `people` | `UserLike` | `{ owner: { displayName: "Alice", email: "alice@example.com" } }` |
| Cleared | `undefined` | `{ name: undefined }` |
