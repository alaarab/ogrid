# Cell Editing

Make your grid editable with built-in editors for text, select, checkbox, and rich select inputs. Double-click or press F2 to start editing a cell. Press Enter or Tab to commit, Escape to cancel.

## Quick Example

```tsx
import { OGrid } from '@alaarab/ogrid';

const columns = [
  { columnId: 'name', name: 'Name', editable: true },
  {
    columnId: 'status',
    name: 'Status',
    editable: true,
    cellEditor: 'select',
    cellEditorParams: { values: ['Active', 'Draft', 'Archived'] },
  },
  {
    columnId: 'approved',
    name: 'Approved',
    editable: true,
    cellEditor: 'checkbox',
  },
];

function App() {
  const handleChange = (event) => {
    console.log(`${event.columnId} changed from ${event.oldValue} to ${event.newValue}`);
  };

  return (
    <OGrid
      columns={columns}
      data={tasks}
      getRowId={(item) => item.id}
      editable
      onCellValueChanged={handleChange}
    />
  );
}
```

## How It Works

Two things must be true for a cell to be editable:

1. `editable={true}` on the `OGrid` component (enables editing grid-wide).
2. `editable: true` on the column definition (opts that column into editing).

### Built-in Editors

| Editor | `cellEditor` | Description |
|--------|-------------|-------------|
| Text | `'text'` (default) | Standard text input. |
| Select | `'select'` | Dropdown with `cellEditorParams.values`. |
| Checkbox | `'checkbox'` | Toggle boolean value on click. |
| Rich Select | `'richSelect'` | Searchable dropdown with keyboard navigation. |

### Rich Select Editor

The rich select editor provides a searchable dropdown list with keyboard support (arrow keys to navigate, Enter to select, Escape to cancel):

```tsx
{
  columnId: 'category',
  name: 'Category',
  editable: true,
  cellEditor: 'richSelect',
  cellEditorParams: {
    values: ['Engineering', 'Design', 'Marketing', 'Sales', 'Support'],
    formatValue: (value) => `Department: ${value}`,
  },
}
```

### Per-Row Editability

Pass a function to `editable` on the column to control editing per row:

```tsx
{
  columnId: 'name',
  name: 'Name',
  editable: (item) => item.status !== 'locked',
}
```

### Custom Editor

Create a custom editor component that receives `ICellEditorProps<T>`. Set `cellEditorPopup: true` to render it in a popover instead of inline:

```tsx
import type { ICellEditorProps } from '@alaarab/ogrid';

function DateEditor({ value, onValueChange, onCommit, onCancel }: ICellEditorProps<Task>) {
  return (
    <input
      type="date"
      value={value as string}
      onChange={(e) => onValueChange(e.target.value)}
      onKeyDown={(e) => {
        if (e.key === 'Enter') onCommit();
        if (e.key === 'Escape') onCancel();
      }}
      autoFocus
    />
  );
}

const columns = [
  {
    columnId: 'dueDate',
    name: 'Due Date',
    editable: true,
    cellEditor: DateEditor,
    cellEditorPopup: true,
  },
];
```

### Value Parsing and Validation

Use `valueParser` to transform or validate user input before it is committed. Return `undefined` to reject the change:

```tsx
{
  columnId: 'age',
  name: 'Age',
  editable: true,
  type: 'numeric',
  valueParser: ({ newValue }) => {
    const num = Number(newValue);
    if (isNaN(num) || num < 0 || num > 150) return undefined; // reject
    return num;
  },
}
```

:::tip
`valueParser` is also called during paste, fill handle, and delete operations -- not just inline editing.
:::

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `editable` | `boolean` | `false` | Enable editing grid-wide (on `OGrid`). |
| `editable` | `boolean \| (item: T) => boolean` | `false` | Enable editing per column or per row (on `IColumnDef`). |
| `cellEditor` | `'text' \| 'select' \| 'checkbox' \| 'richSelect' \| ComponentType` | `'text'` | Editor type or custom component (on `IColumnDef`). |
| `cellEditorPopup` | `boolean` | `false` | Render custom editor in a popover (on `IColumnDef`). |
| `cellEditorParams` | `CellEditorParams` | -- | Parameters passed to the editor (e.g., `{ values: [...] }`). |
| `valueParser` | `(params: IValueParserParams<T>) => unknown` | -- | Parse/validate input before commit. Return `undefined` to reject. |
| `onCellValueChanged` | `(event: ICellValueChangedEvent<T>) => void` | -- | Called after a cell value is committed. Event contains `item`, `columnId`, `oldValue`, `newValue`, `rowIndex`. |

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| Double-click / F2 | Start editing the active cell |
| Enter | Commit edit and move down |
| Tab | Commit edit and move right |
| Escape | Cancel edit |
