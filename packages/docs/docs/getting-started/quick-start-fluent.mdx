# Quick Start: Fluent UI

This guide walks you through building a fully functional data grid with sorting, filtering, and cell editing using the Fluent UI package. This is the recommended choice for Microsoft 365 / SharePoint Framework (SPFx) projects.

## Install

```bash
npm install @alaarab/ogrid-fluent @fluentui/react-components
```

## Full Example

```tsx
import { FluentProvider, webLightTheme } from '@fluentui/react-components';
import { OGrid, type IColumnDef } from '@alaarab/ogrid-fluent';

interface Employee {
  id: number;
  name: string;
  department: string;
  salary: number;
}

const data: Employee[] = [
  { id: 1, name: 'Alice Johnson', department: 'Engineering', salary: 95000 },
  { id: 2, name: 'Bob Smith', department: 'Marketing', salary: 72000 },
  { id: 3, name: 'Carol Williams', department: 'Engineering', salary: 110000 },
  { id: 4, name: 'David Brown', department: 'Sales', salary: 68000 },
  { id: 5, name: 'Eva Martinez', department: 'Marketing', salary: 78000 },
];

const columns: IColumnDef<Employee>[] = [
  {
    columnId: 'name',
    name: 'Name',
    sortable: true,
  },
  {
    columnId: 'department',
    name: 'Department',
    sortable: true,
    filterable: {
      type: 'multiSelect',
      options: ['Engineering', 'Marketing', 'Sales'],
    },
  },
  {
    columnId: 'salary',
    name: 'Salary',
    type: 'numeric',
    sortable: true,
    editable: true,
    valueFormatter: (value) =>
      new Intl.NumberFormat('en-US', { style: 'currency', currency: 'USD' }).format(value as number),
  },
];

export default function App() {
  return (
    <FluentProvider theme={webLightTheme}>
      <OGrid<Employee>
        columns={columns}
        data={data}
        getRowId={(row) => row.id}
        defaultPageSize={10}
        defaultSortBy="name"
        statusBar
        aria-label="Employee directory"
      />
    </FluentProvider>
  );
}
```

:::tip
The `FluentProvider` with a theme is required for Fluent UI components to render correctly. Wrap it around your app root or at least around the `OGrid` component. You can use `webLightTheme`, `webDarkTheme`, or a custom theme.
:::

## Differences from Radix

The API is **identical**. The only differences are:

1. **Import path** -- `@alaarab/ogrid-fluent` instead of `@alaarab/ogrid`
2. **Theme provider** -- Fluent UI requires a `FluentProvider` wrapper with a theme
3. **Visual style** -- Components render with Fluent UI's design language (matching Microsoft 365)

All props, types, hooks, and the Grid API work exactly the same way. You can follow the [Radix Quick Start](./quick-start-radix) for detailed explanations of column definitions, layout modes, and the Grid API -- everything applies here.

## Using with SPFx

In SharePoint Framework web parts, the `FluentProvider` is typically set up at the web part root:

```tsx
import { FluentProvider, webLightTheme } from '@fluentui/react-components';
import { OGrid, type IColumnDef } from '@alaarab/ogrid-fluent';

// Inside your web part's render method:
<FluentProvider theme={webLightTheme}>
  <OGrid
    columns={columns}
    dataSource={myDataSource}
    getRowId={(row) => row.id}
  />
</FluentProvider>
```

For server-side data (e.g., fetching from SharePoint lists via Microsoft Graph), use the `dataSource` prop instead of `data`. See [Server-Side Data](../features/server-side-data) for details.
