# Quick Start: Radix

This guide walks you through building a fully functional data grid with sorting, filtering, and cell editing using the Radix UI package. Radix is the default and lightest OGrid implementation -- no heavy UI framework required.

## Install

```bash
npm install @alaarab/ogrid
```

## Full Example

```tsx
import { OGrid, type IColumnDef } from '@alaarab/ogrid';

interface Employee {
  id: number;
  name: string;
  department: string;
  salary: number;
}

const data: Employee[] = [
  { id: 1, name: 'Alice Johnson', department: 'Engineering', salary: 95000 },
  { id: 2, name: 'Bob Smith', department: 'Marketing', salary: 72000 },
  { id: 3, name: 'Carol Williams', department: 'Engineering', salary: 110000 },
  { id: 4, name: 'David Brown', department: 'Sales', salary: 68000 },
  { id: 5, name: 'Eva Martinez', department: 'Marketing', salary: 78000 },
];

const columns: IColumnDef<Employee>[] = [
  {
    columnId: 'name',
    name: 'Name',
    sortable: true,
  },
  {
    columnId: 'department',
    name: 'Department',
    sortable: true,
    filterable: {
      type: 'multiSelect',
      options: ['Engineering', 'Marketing', 'Sales'],
    },
  },
  {
    columnId: 'salary',
    name: 'Salary',
    type: 'numeric',
    sortable: true,
    editable: true,
    valueFormatter: (value) =>
      new Intl.NumberFormat('en-US', { style: 'currency', currency: 'USD' }).format(value as number),
  },
];

export default function App() {
  return (
    <OGrid<Employee>
      columns={columns}
      data={data}
      getRowId={(row) => row.id}
      defaultPageSize={10}
      defaultSortBy="name"
      statusBar
      aria-label="Employee directory"
    />
  );
}
```

## What You Get

With just this code, the grid provides:

- **Sortable columns.** Click "Name", "Department", or "Salary" headers to sort ascending/descending.
- **Multi-select filter.** Click the filter icon on "Department" to filter by Engineering, Marketing, or Sales.
- **Editable cells.** Double-click any salary cell to edit the value inline.
- **Right-aligned numbers.** The `type: 'numeric'` setting automatically right-aligns the Salary column.
- **Currency formatting.** The `valueFormatter` displays raw numbers as formatted currency.
- **Status bar.** Shows total row count and, when filtered, the filtered count.
- **Pagination.** Built-in pagination controls with configurable page size.
- **Keyboard navigation.** Arrow keys, Tab, and Enter to navigate between cells.
- **Cell selection.** Click and drag to select cell ranges. Copy with Ctrl+C.

## Key Concepts

### Column Definitions

Each column is defined with an `IColumnDef<T>` object. The `columnId` must match a key on your data type (or use `valueGetter` for computed values). Common properties:

- `sortable` -- enables click-to-sort on the column header
- `filterable` -- adds a filter icon with the specified filter type (`text`, `multiSelect`, or `people`)
- `editable` -- allows inline editing (double-click or press Enter on the active cell)
- `type: 'numeric'` -- right-aligns the column and enables numeric parsing
- `valueFormatter` -- formats the display value without affecting the underlying data

### Row Identity

The `getRowId` prop tells OGrid how to uniquely identify each row. This is used for selection, editing, and efficient re-rendering. It should return a `string` or `number`.

### Layout Modes

OGrid supports two layout modes via the `layoutMode` prop:

- `'fill'` (default) -- the grid fills its container's width and height
- `'content'` -- the grid sizes itself based on content

## Adding the Grid API

Use a ref to access the imperative Grid API for programmatic control:

```tsx
import { useRef } from 'react';
import { OGrid, type IOGridApi } from '@alaarab/ogrid';

function App() {
  const gridRef = useRef<IOGridApi<Employee>>(null);

  const handleExport = () => {
    const state = gridRef.current?.getColumnState();
    console.log('Current column state:', state);
  };

  return (
    <>
      <button onClick={handleExport}>Export State</button>
      <OGrid<Employee>
        ref={gridRef}
        columns={columns}
        data={data}
        getRowId={(row) => row.id}
      />
    </>
  );
}
```
