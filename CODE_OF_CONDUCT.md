# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, and assume good faith. Harassment, personal attacks,
and discriminatory behavior are not tolerated in any project space — issues, PRs, discussions,
or elsewhere.

To report unacceptable behavior, contact the maintainer via
[GitHub](https://github.com/alaarab). Reports are handled confidentially.
