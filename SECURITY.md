# Security Policy

## Supported versions

Only the latest published version of the `@alaarab/ogrid-*` packages receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security vulnerabilities. Instead, report privately via
[GitHub security advisories](https://github.com/alaarab/ogrid/security/advisories/new).

You can expect an acknowledgement within a week. Once a fix is available it will be published to npm
and the advisory will be disclosed.
